# Analytical eligibility in longitudinal glioma single-nucleus data

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23809029.svg)](https://doi.org/10.5281/zenodo.23809029)

Code and derived tables for the manuscript *State-specific analytical eligibility and patient
selection in longitudinal glioblastoma single-nucleus RNA sequencing*.

The current analysis uses one public dataset (GSE274546, CARE IDH-wild-type) and works from
malignant-cell metadata: cell counts per sample and state, the published clinical table, and the
ten-state annotation. No expression matrix is reanalysed.

What the repository reproduces:

1. the 52 strictly paired primary-first-recurrence patients and their loss of eligibility at
   5, 10, 20, 50 and 100 cells (`01_care_wt_eligibility.py`);
2. renormalisation of the remaining weights under two filtering conventions;
3. longitudinal MES-fraction change, full cohort versus eligible subset, with a nested bootstrap
   (`07_longitudinal_dmes.py`);
4. eligibility across all ten annotated states, pairwise overlap and recovery statistics
   (`08_states10_eligibility.py`);
5. the recovery-conditioned calibration reference (`10_calibration_recovery.py`);
6. the MGMT-stratified sensitivity analysis reported as Supplementary Note S1
   (`12_mgmt_stratified.py`);
7. Figures 1 and 2 and the supplementary figure (`06_`, `09_`, `11_`).

Scripts `02_decomposition_six_state.py`, `03_decomposition_genomewide.py`,
`04_within_state_de.py` and `05_benchmark.py` are retained for provenance. They belong to earlier
versions of the project and are **not** part of the current manuscript.

## Reproducing the numbers

```bash
python -m pip install -r requirements.txt

# 1. cell counts per sample x state (needs R)
Rscript scripts/dump_counts.R /path/to/malignant_meta_data_2025_01_08.RDS data/care_wt_state_counts.csv

# 2. eligibility, between-group comparison, renormalisation effect
python scripts/01_care_wt_eligibility.py

# 3. decompositions
python scripts/02_decomposition_six_state.py
python scripts/03_decomposition_genomewide.py

# 4. differential testing and simulation
python scripts/04_within_state_de.py
python scripts/05_benchmark.py

# 5. longitudinal change in the eligible subset vs the full cohort
python scripts/07_longitudinal_dmes.py

# 6. figures
python scripts/06_figures.py
```

Set `GLIOMA_DATA` if the inputs live somewhere other than `./data`.

## Two filtering conventions

`scripts/01_care_wt_eligibility.py` uses the **paired-state** convention: a state is kept
only when it reaches 20 cells at both endpoints, and both endpoints are renormalised over
that shared set. This is the convention a paired state-specific analysis requires. A
**per-endpoint** convention (each endpoint drops only its own sub-threshold states) gives a
much smaller renormalisation effect: median 0.0003, mean 0.003, maximum 0.046, 26/27 below
0.02. The two conventions differ by an order of magnitude, so the manuscript reports both
and names the one used for each number.

## A note on defining the pairs

The pair set is defined by the **specimen-level clinical annotation** published with the
cohort, not by the aliquot identifier string. The identifier table disagrees with the
clinical labels for three specimens and omits two second time points, so an
identifier-based definition yields 49 pairs instead of 52 and, for one patient (P45),
orders the two time points backwards. This is documented in `outputs/` after running
step 2 and is the reason the clinical annotation is treated as authoritative.
