# Cell-count filtering in paired glioma single-cell analyses

Code and derived tables for the manuscript *"Patient exclusion and compositional changes
under cell-count filtering in longitudinal single-cell analyses of glioma"*.

The repository separates two consequences of a minimum cell-count threshold that are
usually conflated:

* **who is analysed** — the threshold removes patients, and the patients it removes are
  not exchangeable with those retained;
* **what is measured** — among patients who survive the threshold, dropping
  sub-threshold states and renormalising the remaining weights moves the composition
  estimate by a median of 0.0045.

The analysis uses three paired expression cohorts and one cohort with malignant-cell
metadata only. All data are public; nothing patient-identifiable is redistributed here.

## What is here

```
config.py                 paths and constants (override with GLIOMA_DATA / GLIOMA_OUT)
scripts/
  dump_counts.R           per-sample x per-state cell counts from the CARE-WT metadata
  01_care_wt_eligibility.py   strict pairs, thresholds, retained vs excluded, distortion
  02_decomposition_six_state.py   62-gene decomposition, CARE and GSE292130
  03_decomposition_genomewide.py  two-state decomposition, GSE174554 (16,044 genes)
  04_within_state_de.py   paired within-state differential testing + resolution
  05_benchmark.py         simulation separating contribution from effect
  06_figures.py           Figures 1-3
outputs/                  derived tables and figures (regenerated by the scripts)
data/                     inputs; see data/README.md
```

## Reproducing the numbers

```bash
python -m pip install -r requirements.txt

# 1. cell counts per sample x state (needs R)
Rscript scripts/dump_counts.R /path/to/malignant_meta_data_2025_01_08.RDS data/care_wt_state_counts.csv

# 2. eligibility, between-group comparison, renormalisation effect
python scripts/01_care_wt_eligibility.py

# 3. decompositions
python scripts/02_decomposition_six_state.py
python scripts/03_decomposition_genomewide.py

# 4. differential testing and simulation
python scripts/04_within_state_de.py
python scripts/05_benchmark.py

# 5. figures
python scripts/06_figures.py
```

Set `GLIOMA_DATA` if the inputs live somewhere other than `./data`.

Expected values from step 2 on the published inputs:

```
strict pairs 52      thresholds (0,5,10,20,50,100): 52, 33, 32, 27, 18, 15
four-way both/TP only/R1 only/both fail: 27 / 5 / 11 / 9   exact McNemar P = 0.210
retained vs excluded, primary cells: 2,827 vs 1,371 (95% CI 700 to 3,079)
retained vs excluded, recurrence MES fraction: 0.071 vs 0.011 (0.015 to 0.102)
distortion among retained: median 0.0045, mean 0.028, max 0.258, r = 0.79, 21/27 < 0.02
```

## A note on defining the pairs

The pair set is defined by the **specimen-level clinical annotation** published with the
cohort, not by the aliquot identifier string. The identifier table disagrees with the
clinical labels for three specimens and omits two second time points, so an
identifier-based definition yields 49 pairs instead of 52 and, for one patient (P45),
orders the two time points backwards. This is documented in `outputs/` after running
step 2 and is the reason the clinical annotation is treated as authoritative.
